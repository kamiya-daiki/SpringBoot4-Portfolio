
# 非機能要件定義書

## 1. 想定利用環境

本システムは社内業務補助システムとして利用することを想定する。

* 利用環境：社内LAN
* 想定ユーザー数：10名程度
* 想定同時接続数：10ユーザー以下

---

# 2. セキュリティ

## 2.1 認証・認可

本システムではユーザー認証を実施する。

#### 認証方式

* ユーザーID（メールアドレス）
* パスワード認証

ユーザー権限は以下の2種類とする。

| 権限 | 概要 |
| ------ | ------------------ |
| 一般ユーザー | 自身のタスク管理 |
| 管理者 | 全ユーザーのタスク閲覧、ユーザー管理 |

管理者は以下の操作が可能。

* 全ユーザーのタスク閲覧
* ユーザー削除
* 権限変更

#### システム上、管理者を0人にすることはできない。

---

# 2.2 パスワード管理

パスワードは平文で保存せず、以下の方式で保存する。

* ハッシュアルゴリズム：BCrypt
* フレームワーク：Spring Security

---

# 2.3 通信の暗号化

本システムは社内LAN環境での利用を想定している。

本来は通信の機密性確保のためHTTPS（TLS）による暗号化を実施することが望ましいが、
本ポートフォリオでは開発環境の簡易構築を優先しHTTP通信としている。

将来的に外部ネットワークからの利用が想定される場合は、
HTTPSによる通信暗号化を実装することを前提とする。

---

# 2.4 脆弱性対策

本システムでは以下のセキュリティ対策を実施する。

* Spring Securityによる認証制御
* パスワードのハッシュ化
* 入力値検証
* 例外ログの記録

また、使用するミドルウェアはサポート期限を確認し、
必要に応じてアップデートを実施する。

#### 使用ミドルウェア

| ソフトウェア | バージョン |
| ----------- | -------- |
| Java | 21 (LTS) |
| Spring Boot | 4.0.2 |

---

# 3. ログ管理

本システムでは以下のログを取得する。

## 3.1 アクセスログ

#### 取得項目

* 日時
* ユーザーID
* IPアドレス
* アクセスURL
* HTTPメソッド
* レスポンスステータス

#### 用途

* 不正アクセス調査
* 障害調査

#### 保存期間

* 6ヶ月

---

## 3.2 操作ログ

ユーザー操作の追跡を目的として以下のログを取得する。

#### 対象操作

* ログイン
* ログアウト
* タスク登録
* タスク更新
* タスク削除
* ユーザー管理操作

#### 取得項目

* 実行日時
* ユーザーID
* 操作種別
* 対象データID
* 実行結果

#### 保存期間

* 1年

---

## 3.3 システムログ

アプリケーション内部のイベントおよびエラー情報を記録する。

#### 対象

* 例外発生
* システム起動／停止
* DB接続エラー

#### 保存期間

* 3ヶ月

---

# 4. バックアップ

データ消失への対策として以下のバックアップを実施する。

* データベース：1日1回バックアップ
* 障害発生時はバックアップから復旧

---

# 5. 運用・保守

本システムの運用および保守について以下を実施する。

* Java / Spring Bootのサポート期限の確認
* 必要に応じたバージョンアップ
* 障害発生時のログ調査
